## 0. プロジェクト概要

- **用途**: 主に自分用だが、数人の友人にもVercelデプロイ経由で使用させる想定。
- **プラットフォーム**: スマホ利用がメイン。PWAとして疑似スマホアプリ化する。将来的にはWebへの一般公開も視野に入れている。
- **特徴**: Next.jsを用いて、SVGフィルター等を使ったリッチなUI（Gooeyエフェクトなど）を実装済み。モバイルでのパフォーマンスフォールバックも考慮する。

## 1. アプリの目的（Why）
- Todo機能を核に、日々の行動と気づきを軽く記録し、継続しやすい導線で振り返りに繋げる。

## 2. 主要コンセプト（What）
- **1日の最小単位は Todo**（やること/やったこと）
- Todo に **短い日常メモ**（感情・体調・学び等）を紐づけられる
- その日を「終える」動作で、一覧/ふりかえりに自然に繋がる
- **よくある簡素なTodo UIではなく、「触っていて楽しい」直感的な操作感**
  - 視覚的なフィードバックとモーションを重視し、画面遷移も「どこからどこへ移動したか」が物理的に視認できるようにする（パッと切り替わるだけにしない）

## 3. ユーザー像（Who）
- 日々のやることはあるが、日記は続かない人
- 目的は「完璧な記録」ではなく「継続と気づき」

## 4. 機能要件（MVP）
### 4.1 Todo
- **作成**: テキスト入力でTodo追加
- **完了/未完了**: チェックでトグル
- **編集**: テキストの修正
- **削除**: 取り消し可能にするかは後で判断（まずは削除可）
- **並び替え**: 優先度またはドラッグ（MVPでは「追加順 + 完了は下」に寄せる）
- **カテゴリ**: `routine`（ルーティン）| `health`（健康）| `physical`（体の動き）| `knowledge`（学び）| `activity`（活動）| `creative`（創作）の6種類

### 4.2 日常記録（ログ）
- **当日ログ**: その日のメモ（短文）を追記できる
- **Todoとの関係**: Todo単位にメモを付ける／または「当日の自由メモ」を持つ（方針は後述の「未決事項」）

### 4.3 日付/ふりかえり
- **日付切り替え**: 今日/過去日の表示切替
- **一覧**: 日毎のTodo + メモを見返せる

### 4.4 タスクソース（Buffs / Overdue / Next）
- **Buffs**: AIが用意した「QOLが上がる」ちょっとしたタスク一覧を表示
  - **Todayへの追加**: 選んだタスクを当日のTodoとして追加できる
- **Overdue**: 達成できなかったタスク（期限超過/持ち越し）を一覧できる
  - **再投入**: 当日のTodoとして再投入できる（操作は後で確定）
- **Next**: 当日ではないが今後やる必要があるタスクを管理できる
  - **追加**: Nextへタスク追加
  - **Todayへの追加**: Nextのタスクを当日のTodoへ追加できる

### 4.5 アカウント（Login / Profile）
- **Login**: サインアップ/サインイン
- **ログイン後導線**: ログイン直後に「アイコンをかっこよく表示する」短い演出画面を挟み、その後 `today` へ遷移したい
- **Profile**: ユーザーのプロフィール画面 + 各種設定

## 5. 非機能要件（MVP）
- **継続性**: 入力が軽い（クリック数・迷いを減らす）
- **パフォーマンス**: 体感が軽い（入力遅延がない）
- **可用性**: ローカル開発で再現できること
- **データ**: Supabase PostgreSQL + Drizzle ORM で永続化

## 6. 画面（現時点）
ルート名は現状の意図を示す（実装の実パスに合わせて更新する）。

### 6.1 `today/page`（ホーム）
- 当日のTodoを **表示/完了/編集/削除/追加** できる
- `buffs` からの遷移先（追加導線の受け口）

### 6.2 `buffs/page`
- QOLが上がるような「ちょっとしたタスク一覧」
- `today` から遷移可能
- 選択したタスクを **当日のTodoへ追加** できる

### 6.3 `overdue`（画面名・パスは調整）
- 達成できなかったタスクの一覧
- 当日のTodoへ「持ち越し/再投入」できる（操作の最終形は未決）

### 6.4 `next`（まだ未作成）
- 当日ではないが、今後やる必要があるタスクの画面
- **追加** と **当日タスクへの追加** が可能

### 6.5 `profile`
- ユーザーのプロフィール画面
- 各種設定（詳細はMVP後に拡張）

### 6.6 `login`
- サインアップ / サインイン
- ログイン後、短い演出（アイコンをかっこよく表示）を挟んで `today` へ遷移

### 6.7 ナビゲーション（暫定）
- `layout` 内のタブ/ボタンで画面遷移（見た目の凝りは後回し、まず動線優先）

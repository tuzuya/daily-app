# ScrollingText モーション調整ガイド

このドキュメントでは、モチベーションテキストの流れ方を調整するために、どの数値が何に効くのかを説明します。

## 1) 編集するファイル

- `src/app/components/ScrollingText.tsx`
- `src/app/global.css`

## 2) 主要な時間パラメータ

### `CYCLE_MS`
- ファイル: `src/app/components/ScrollingText.tsx`
- 現在値: `3800`
- 役割: フレーズを次に切り替える周期
- ルール: CSS のアニメーション時間と一致させる

### `.motivation-forward` / `.motivation-reverse` の duration
- ファイル: `src/app/global.css`
- 現在値: `3.8s`
- 役割: 1フレーズ分の動き全体の長さ
- ルール: `CYCLE_MS / 1000` に合わせる

この2つがズレると、フレーズの切替タイミングと移動が噛み合わず、重なりや停止感が出ます。

## 3) keyframes で速度が決まる仕組み

現在の keyframes のチェックポイント:

- `0%`
- `6%`
- `12%`
- `28%`
- `46%`
- `64%`
- `82%`
- `90%`
- `100%`

### 重要な考え方
2つのチェックポイント間の「移動距離」と「区間の長さ」で速度が決まります。

- 短い区間で大きく動く: 速く見える
- 長い区間で少しずつ動く: 遅く見える

## 4) 現在の動作フェーズ（3.8秒設定時）

- Burst-in: `0% -> 12%`（約 `456ms`）
- Slow drift: `12% -> 90%`（約 `2964ms`）
- Exit: `90% -> 100%`（約 `380ms`）

計算式:

- `phaseMs = CYCLE_MS * (phasePercent / 100)`
- `burstMs = CYCLE_MS * (12 / 100)`
- `driftMs = CYCLE_MS * ((90 - 12) / 100)`
- `exitMs = CYCLE_MS * ((100 - 90) / 100)`

## 5) 調整できる位置パラメータ

### 右 -> 左 (`motivation-burst-from-right`)

- 開始: `120%`（画面右外）
- 中間: `56%`, `28%`, `12%`, `2%`, `-4%`, `-8%`, `-10%`
- 終了: `-130%`（画面左外）

### 左 -> 右 (`motivation-burst-from-left`)

右->左の値を符号反転したもの:

- 開始: `-120%`
- 中間: `-56%`, `-28%`, `-12%`, `-2%`, `4%`, `8%`, `10%`
- 終了: `130%`

## 6) どの値を変えると何が変わるか

### Burst の勢い（侵入インパクト）
主にここを調整:

- `0%`, `6%`, `12%` の位置
- `0% -> 6% -> 12%` の区間幅

目安:

- 勢いを強くする: 開始オフセットを大きく（`120% -> 140%`）し、Burst 区間を短く（`12% -> 10%`）
- 勢いを弱める: 開始オフセットを小さく（`120% -> 100%`）し、Burst 区間を長く（`12% -> 15%`）

### Drift の滑らかさ（低速区間の質感）
主にここを調整:

- `12% -> 90%` 内の中間点（`28, 46, 64, 82, 90`）
- ステップごとの移動量を徐々に小さくする

良い減速パターン例（右->左）:

- `28 -> 12`（大）
- `12 -> 2`（中）
- `2 -> -4`（小）
- `-4 -> -8`（より小）
- `-8 -> -10`（最小）

### Exit のキレ
主にここを調整:

- `90%` 時点の位置
- `100%` の位置（`-130%` / `130%`）
- Exit 区間の長さ（`90% -> 100%`）

目安:

- キレよく消す: 終端オフセットを大きく、または Exit 区間を短く
- やわらかく消す: 終端オフセットを小さく、または Exit 区間を長く

## 7) 透明度・傾きの調整

- 現在の opacity: `0 -> 0.92 -> 1 -> 1 -> 0`
- 現在の skew: 侵入/退出で強め、Drift で `0` 付近

動きが強すぎる場合の対策:

- skew を弱める（例: `8deg -> 5deg`）
- 序盤の opacity を上げる（出始めのチラつき軽減）

## 8) 安全に調整するチェックリスト

1. 左右 keyframes は必ず鏡合わせにする
2. 各方向で位置が単調に進むようにする
3. `CYCLE_MS` と CSS duration を揃える
4. 1回の調整で1グループだけ触る（時間 -> 位置 -> 傾き/透明度）
5. 少し変えて毎回見た目を確認する

## 9) すぐ使える調整レシピ

### A) もっと「シュッ」と出したい
- `0%`: `120% -> 145%`
- Burst 終了: `12% -> 10%`

### B) 低速区間を長くしたい
- Drift 終了: `90% -> 93%`
- `100%` の終端位置はそのまま

### C) 全体を穏やかにしたい
- 開始/終了オフセット: `120/130 -> 95/105`
